fallback 的两个不确定性阈值作为二维格点联合校准，在目标风险约束下尽量提高覆盖率并减少不必要检索。 09 PEEK MIT CSAIL / Stanford · PEEK 在 agent prompt 中维护固定大小的 context map，缓存可复用的外部上下文定向知识，让长期反复访问同一语料或代码库的 Agent 更快、更便宜。 10 m3BERT Microsoft / 厦门大学 / 上海交大 · m3BERT 面向搜索和广告检索，把 embedding 维度与 transformer 层数都做成可裁剪的 Matryoshka 结构，并用 10B query-document 点击对做 Web 域预训练。 11 D3-Subsidy 滴滴 / 港大 / 哈工大 / 香港理工 · D3-Subsidy 用前缀条件扩散模型规划城市级未来轨迹，再通过逆动力学和拉格朗日对偶映射落到订单-司机补贴，线上 A/B 提升 Rides、GMV 和 DRV。 12 RAGR 多校 · Review-Augmented Generative Recommendation 把 review 变成用户序列里的反馈事件，再用 DPO 拉回 item 预测。 13 DADF 快手 · Watch-Time
